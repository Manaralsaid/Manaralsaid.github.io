# Dr. Manar Alsaid Academic Website

This repository contains the GitHub Pages website for Dr. Manar Alsaid.

## Publishing instructions

1. Create a public GitHub repository named exactly:

   `Manaralsaid.github.io`

2. Upload all files in this folder to the root of the repository.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose branch **main** and folder **/root**.
6. Visit:

   `https://Manaralsaid.github.io`

## Main files

- `index.html` — website content
- `styles.css` — website styling
- `.nojekyll` — prevents GitHub Pages from processing the site with Jekyll
- `assets/Manar_Alsaid_CV_June_2026.docx` — downloadable CV

## Editing

Most text can be edited directly in `index.html`. Colors, spacing, and layout can be edited in `styles.css`.
