# manaralsaid.github.io

Personal academic website of **Dr. Manar Alsaid**, Assistant Professor of Computer Science &amp; Information Systems at East Texas A&M University.

Research in artificial intelligence, cybersecurity, data science, misinformation detection, and AI-supported education.

## Live site
https://manaralsaid.github.io/

## Structure
- `index.html` — single-page site (About, Research, Publications, Teaching, Grants, Awards, Service, Contact)
- `styles.css` — responsive theme with light/dark mode
- `script.js` — dark-mode toggle, mobile navigation, publication filtering
- `assets/Manar_Alsaid_CV.docx` — downloadable CV

Served by GitHub Pages from the `main` branch.
